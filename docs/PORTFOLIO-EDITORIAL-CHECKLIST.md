# Portfolio Editorial Checklist

Use this checklist before publishing any Project CPT item. The goal is to build local relevance from real project evidence without inventing cities, materials, finishes, reviews, prices, or outcomes.

## Required verified facts

Do not publish until these are known from project records or the owner/client:

- Project type: kitchen, bathroom, closet, laundry/pantry, home office, countertop, or other accurate category.
- Project location: city/community only when verified. Do not infer a city from a ZIP code, photo, lead source, or nearby landmark.
- Cabinet style/collection only when verified.
- Cabinet color/finish only when verified.
- Countertop material and named color only when verified.
- Scope actually performed by ZEUS. Do not claim design, demolition, plumbing, electrical, fabrication, installation, or other work unless it was part of the project.
- Photography: only real project images ZEUS has permission to use.

## Recommended project page structure

1. **H1:** descriptive project name based only on verified facts.
2. **Summary:** 2–3 sentences explaining the room and verified ZEUS scope.
3. **Project details:** compact fact list containing only confirmed location, cabinet style/finish, countertop, and scope.
4. **Design / installation notes:** explain observable or documented decisions; do not invent client motivations or problems.
5. **Gallery:** real photos with factual alt text describing what is visible. Add location to alt text only when verified and useful.
6. **Related services:** link to the relevant cabinet, countertop, or custom-space service pages.
7. **Related style/material:** link to the relevant collection or countertop material page when applicable.
8. **CTA:** consultation link.

## SEO rules

- A project page is a case study, not a doorway page for a city keyword.
- Use the verified city naturally in title/H1/body only when it genuinely identifies the project.
- Never create multiple near-duplicate project pages from one job to target neighboring cities.
- Never add `Review`, `AggregateRating`, fabricated testimonials, fake completion dates, fake savings, or unsupported performance claims.
- Do not publish a project whose only content is generic sales copy plus a location name.
- Each project should link back to at least one relevant service page. Service pages may link to relevant published projects once they exist.

## Image checklist

- Use the strongest real finished-project image as featured image.
- Prefer original project photography over stock images.
- Alt text describes the visible room/material/style; it is not a keyword list.
- Do not identify a city in alt text unless the project location is verified.
- Avoid duplicate images unless they add context to a different page.

## Minimum publish threshold

A Project CPT item is ready to publish only when it has:

- at least one real project image;
- a factual summary and verified scope;
- enough verified details to distinguish it from generic service copy;
- at least one relevant internal service/style/material link;
- no invented facts.

If the threshold is not met, keep the item as a draft. Empty Portfolio is preferable to fabricated case studies.
