# Portfolio Project Editorial Template

Use this template only for a real completed ZEUS project. Leave unknown fields blank; never infer them from photographs.

## Required verified inputs before publishing

- Project display name (neutral naming is acceptable, e.g. “White Shaker Kitchen” only if the style is verified)
- Project type: kitchen / bathroom / closet / laundry / pantry / home office / other
- Real photographs approved for website use
- Cabinet style/finish only when verified
- Countertop material only when verified
- City/community only when verified and appropriate to disclose

## Optional verified inputs

- Scope performed by ZEUS
- Storage/layout features
- Special fabrication or installation details
- Before photographs
- Approximate completion date

## Page structure

### H1
`[Verified project descriptor]`

### Intro (60–100 words)
State only what can be seen or verified: room type, verified cabinet style/material and the work ZEUS performed. Avoid subjective claims such as “luxury,” “best,” or “perfect” unless they are purely descriptive and supportable.

### Project details
Use only verified fields. Omit empty rows rather than displaying “unknown.”

### Design and layout
Describe visible, verified design decisions. Examples: drawer banks, tall pantry cabinets, island cabinetry, open shelving, glass doors, waterfall edge — only when present and verified.

### Cabinetry
Name the door style, finish or collection only when verified.

### Countertops
Name quartz/granite/porcelain/marble or a specific product only when verified.

### Gallery
Every meaningful image gets concise alt text describing visible content, not SEO keyword stuffing. Decorative duplicates should use empty alt text when appropriate.

### Related services
Link to the closest relevant service page, then Cabinet Styles or Countertops when applicable, and Consultation.

## Metadata pattern

**SEO title:** `[Verified descriptor] | ZEUS Cabinets & Countertops`

**Meta description:** 120–155 characters describing the verified project scope without invented location, material or outcome claims.

## Publication guardrails

- Never invent a city from EXIF, filename, customer address or visual clues.
- Never infer quartz vs. natural stone from appearance alone.
- Never identify a cabinet collection from appearance alone.
- Never create testimonial/review schema from informal customer messages without explicit publication approval and source verification.
- Never seed placeholder projects on production.
- Do not expose customer names, street addresses, invoices or identifying documents.
