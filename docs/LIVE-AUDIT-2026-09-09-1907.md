# ZEUS live audit — 2026-09-09 19:07 ET

## Why this audit exists

A direct production check found an important distinction between WordPress database content and the public pages rendered by the current ZEUS theme.

Several commercial pages use WordPress `page-{slug}.php` templates that hard-code the visible page copy. Updating the Page object's `post_content` through WordPress therefore succeeds in the database but does **not** change the text visitors see while the page-specific template remains active.

This affects interpretation of the 2026-09-09 WordPress content edits. Treat the DB copy as useful planned/source copy, but do not describe those edits as visible production changes unless the matching PHP template was also updated and deployed.

## Production pages confirmed template-driven

Direct production rendering confirms the theme versions are currently visible for at least:

- `/cabinets/kitchen-cabinets/` -> `theme/zeus/page-kitchen-cabinets.php`
- `/cabinets/bathroom-cabinets-vanities/` -> `theme/zeus/page-bathroom-cabinets-vanities.php`
- `/custom-spaces/home-office/` -> `theme/zeus/page-home-office.php`
- `/custom-spaces/closets/` -> `theme/zeus/page-closets.php`
- `/countertops/granite/` -> `theme/zeus/page-granite.php`

The same architecture applies to the other RC4C/RC4D page-specific templates unless individually disproved.

## Consequence for the 2026-09-09 SEO pass

The WordPress DB edits made to Home Office, Closets, Kitchen and Bathroom are not sufficient by themselves to change visible production copy. Their intended SEO improvements need to be synchronized into the page-specific PHP templates before/with the next theme deploy.

This does **not** invalidate GSC annotations; it changes what should be attributed to them. Separate DB-content edits from actual template deploys when evaluating ranking movement.
