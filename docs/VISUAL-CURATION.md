## Portfolio rules

1. Only publish real completed projects with project photography verified as ZEUS work.
2. City/location may be shown only when supported by the project record/filename/source.
3. Do not invent cabinet style, countertop material, room type, project scope, price, or completion date.
4. New uploaded media may be grouped into a Project CPT only when the image series belongs to one job with reasonable confidence.
5. Reject low-quality, duplicate, construction-only, badly cropped, privacy-sensitive, or owner-disliked frames from featured/gallery roles; preserve them in Media Library unless the owner explicitly requests deletion.
